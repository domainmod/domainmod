This section of the User Guide details how to add various Assets to DomainMOD, such as your Account Owners, Domain Registrars, Domain Registrar Accounts, Hosting Providers, and so on.

If you've just finished installing DomainMOD please see the First Run section for instructions on how to get up-and-running.

Add An Owner

  1. Click on Assets on the main menu.

  2. Under Shared, click Account Owners.

  3. Click the Add Owner button.

  4. Enter the Owner's Name.

  5. Click the Add Owner button.

Add a Domain Registrar

  1. Click on Assets on the main menu.

  2. Under Domains, click Domain Registrars.

  3. Click the Add Registrar button.

  4. Enter the Registrar's Name and then click the Add Domain Registrar button.

And that's all there is to it, you've just added your first Domain Registrar!

Now it's time to add your first Domain Registrar Account.

Add a Domain Registrar Account

  1. Click on Assets on the main menu.

  2. Under Domains, click Domain Registrar Accounts.

  3. Click the Add Registrar Account button.

  4. Choose the Domain Registrar and Account Owner that this registrar account belongs to, enter your account Username, and then click the Add Registrar Account button.

Add a Hosting Provider

  1. Click on Assets on the main menu.

  2. Under Hosting, click Hosting Providers.

  3. Click the Add Hosting Provider button.

  4. Enter the Hosting Provider's Name and then click the Add Hosting Provider button.

Now it's time to add your first Hosting Account.

Add a Hosting Account

  1. Click on Assets on the main menu.

  2. Under Hosting, click Hosting Accounts.

  3. Click the Add Account button.

  4. Choose the Hosting Provider and Account Owner that this hosting account belongs to, enter your account Username, and then click the Add Hosting Account button.

Add a Hosting Service Type

DomainMOD comes with a set of service types, such as Shared, VPS, and Email, so you only need to add one if none of them fit.

  1. Click on Assets on the main menu.

  2. Under Hosting, click Hosting Service Types.

  3. Click the Add Type button.

  4. Enter the Service Type and then click the Add Service Type button.

Once you have a hosting account, you can start adding your hosting services.

Add an SSL Provider

  1. Click on Assets on the main menu.

  2. Under SSL Certificates, click SSL Providers.

  3. Click the Add SSL Provider button.

  4. Enter the SSL Provider's Name and then click the Add SSL Provider button.

Now it's time to add your first SSL Provider Account.

Add an SSL Provider Account

  1. Click on Assets on the main menu.

  2. Under SSL Certificates, click SSL Provider Accounts.

  3. Click the Add SSL Account button.

  4. Choose the SSL Provider and Account Owner that this SSL account belongs to, enter your account Username, and then click the Add SSL Provider Account button.
