DomainMOD gives you a few options for adding your domains, so you should read through the below sections to determine which will work best for you.

Note

Before adding your domains to DomainMOD you must first create some Assets. If you've just finished installing you should visit the First Run section, which will walk you through creating the Assets that are required to start using DomainMOD. Alternatively, you can use the CSV Importer to import all of your domain data without having to create any Assets first.

CSV Importer

The CSV Importer allows you to import all of your domain data into DomainMOD using a CSV template. This is a brand new feature as of DomainMOD v4.19, but all testing has gone very well, and I've personally imported quite a few test CSV files with 100% accuracy. Keep in mind that the CSV Importer only imports new domains, it does not update domains that are already in your DomainMOD database.

Add domains using the CSV Importer »

Domain Queue

One of the easiest options for adding domains is to use the Domain Queue, which allows you to supply a list of domains and let DomainMOD take care of the rest (and in some cases you don't even need to supply the list of domains, it will be automatically retrieved from your registrar account).

If your registrar has an API that DomainMOD supports, the Domain Queue uses it to retrieve the information required to add your domains, so before using this option make sure your API credentials have been saved with your registrar account. If your registrar isn't supported, you can still paste in a list of your domains, and DomainMOD will look up their details using RDAP, the public replacement for WHOIS, or WHOIS itself for domains that RDAP doesn't cover.

Add domains using the Domain Queue »

Bulk Updater

The Bulk Updater also allows you to supply a list of domains to be added, however you need to manually choose the options for the domains you're adding, and all of the domains will have the same settings. The Bulk Updater generally works best if you're adding a list of newly registered domains, since they will have the same expiry date and will generally have the same settings.

Add domains using the Bulk Updater »

Manually

Domains can also be added one-by-one, which allows you to choose custom settings for each domain.

Adding A Domain Manually

  1. Click on Domains on the main menu.

  2. Click the Add Domain button on the Domains page.

  3. Enter the Domain that you want to add.

  4. Fill in all of the relevant details for the domain, such as the expiry date, registrar account, DNS profile, and so on.

  5. Click the Add Domain button.

That's it, your domain has been added to DomainMOD!

Note

If this is the first time you've added a domain from this registrar with this TLD you will need to enter the fees associated with this registrar/TLD combination. After adding the domain you will be presented with a notice that will walk you through how to add the new fee. Until the fee is added, the domain is hidden from the Domains list, and you can find the fees still to add in the Missing Fees section of Assets -> Domain Fees (Assets -> SSL Fees for SSL certificates).

UPDATE: As of v4.23.0, if you don't care about keeping track of fees, you can now set all missing fees to 0 with the click of a button.
