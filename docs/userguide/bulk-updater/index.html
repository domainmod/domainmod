The Bulk Updater allows you add or modify multiple domains at the same time, whether it's a couple dozen or a couple thousand, all with a few clicks. Using the Bulk Updater is simple, it's just like adding or modifying a single domain, but instead of supplying one domain you supply a list of domains, and the Bulk Updater does the rest.

Usage

For this example we're going to use the Bulk Updater to add domains. However, it can also be used to renew domains, change the status of the domains, change the category, DNS profile, and hosting service of the domains, and so on.

Adding Domains Using The Bulk Updater

  1. Click on Bulk Updater on the main menu.

  2. On the dropdown menu on the Bulk Updater page, choose Add Domains.

  3. In the Domains to add text area, paste in a list of domains that you want to add, one domain per line.

  4. Fill in all of the relevant details for the domain, such as the expiry date, registrar account, DNS profile, and so on.

  5. Click the Add Domains button.

That's all there is to it, you've just added some domains in bulk!

Finding Domains

As of v4.27.0, every action except Add Domains has a Find a domain to add to the list box above the list of domains. For Update Custom Domain Field, the box is on the second step, with the list. Type part of a domain name, then pick it from the results, which show each domain's status, to add it to the list as a new line. You can still type or paste domains straight into the list.

Changing the Hosting Service

As of v4.27.0, the Change Hosting Service action links every domain on the list to the hosting service you choose. Choose None to remove their links. Cancelled services aren't offered. Add Domains also has an optional Hosting Service menu.
