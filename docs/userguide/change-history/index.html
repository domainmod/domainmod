As of v4.27.0, DomainMOD keeps a change log (or audit trail) of the changes made to your domains, hosting services, SSL certificates, and watched domains: what changed, the old and new values, when the change happened, who made it, and what made it. Changes are recorded from the add and edit pages, Refresh and the scheduled Refresh Domains task, the Bulk Updater, the CSV Importer, the Domain Queue and SSL Queue, Mark Renewed on a hosting service, asset and fee changes, deleted custom fields, maintenance, and database upgrades.

The history starts when DomainMOD is installed, or when an administrator runs Upgrade Database for v4.27.0, so changes made before then aren't listed.

Viewing Changes

Click Change History on the main menu. Every user can see it, including read-only users. The newest changes come first, with these columns: When, Item, Type, What Changed, From, To, Source, By, and Note. Changes that DomainMOD made itself, such as a scheduled refresh, show DomainMOD in the By column.

When one action changed several things, such as a Bulk Updater action, its Source shows a link such as "25 changes to 25 items", which lists every change it made.

The Reporting page's Recent Domain Changes tile opens the list with the last 30 days of domain changes.

Filters

The list shows the last 30 days to start with. You can narrow it down with these filters, then click Apply filters:

  • Type: Domain, Hosting Service, SSL Certificate, or Watched Domain
  • Item Name: part of a domain, hosting service, or certificate name
  • Source: where the change came from, such as Add or Edit Page, Bulk Updater, Refresh, or Scheduled Refresh
  • By: a user, or DomainMOD
  • What Changed: a field, such as Expiry Date or DNS Profile, or one of your custom fields
  • Date: Today, Last 7 Days, Last 30 Days, Last 90 Days, All Time, or a Custom Range

Each filter in use is shown above the list, where you can remove it, and Clear filters removes them all.

Exporting

Click Export to download the changes the list is showing, with your filters applied, as a CSV file. The export also includes each item's ID, the stored values, and, for an added or deleted item, a snapshot of its values, so a deleted item's details can be recovered (a very large item's snapshot may be shortened or leave some fields out).

On the Edit Pages

The domain, hosting service, SSL certificate, and watched domain edit pages each have a Change History section with that item's recent changes, and a link to see all of them on the Change History page. On a live domain's page (one that isn't Expired or Sold), the section also shows the domain's automatic check status, such as when it was last checked and when its next check is due.

How Long Changes Are Kept

Administrators can set how long changes are kept in Administration -> System Settings, under Change History: 1, 2, 3, 5, or 10 years, or forever. The default is 3 years. Older changes are removed by the daily System Cleanup task. The change history is included in backups, so a shorter time keeps them smaller, and Administration -> Backup & Restore shows how much of the database it takes up.

Restores

When you restore a backup, the Change History becomes the backup's own, and the Change History page shows a note such as "This database was restored from a backup on 2027-01-15", since changes made between the backup and the restore aren't shown. The changes recorded before the restore are removed if the backup has no change history (such as one from before v4.27.0), was incomplete, or came from a newer version of DomainMOD. They're also removed if the restore didn't finish or its result couldn't be verified. The page says why, and the Refresh Domains task is turned off, so an administrator should enable it again in the Task Scheduler if it was in use, once a complete backup has been restored if the database may be partly restored.
