Support

Support Portal

Questions, problems, and feature requests (including new registrar integrations) go in our Support Portal. Other users can vote on the requests that matter most to them, which helps us decide what to work on next.

https://support.domainmod.org

The Support Portal also has a project Roadmap, built automatically from what users have submitted and where each item stands (Planned, In Progress, Completed, and so on), so you can see how development is progressing.

View the Project Roadmap

Bug Reports

The Support Portal is the right place for any problem, bugs included. If you're a developer and can point to the code, you can submit a GitHub issue instead. Please report each bug in one place only, not both.

Report a Bug on GitHub

Pull Requests

Before submitting a pull request, please contact the maintainers of the repository to discuss the change. See Contributing for more details.

Security Issues

Security vulnerabilities should never be reported publicly, so please follow our security policy instead.
